CASCADE (team FINORA) is a cash-flow risk radar for freelancers and gig workers. It projects 60 days of cash flow, then uses Gemini 2.5 Flash on Vertex AI to propose compound what-if scenarios (e.g. a late client payment plus an unexpected bill) built only from the user's own record ids. A deterministic engine, never the AI, simulates every scenario with exact integer maths; Gemini then explains the verified numbers in plain language and extracts terms from loan documents with page citations. Cloud Run hosts the FastAPI backend (finora-api). Cloud Firestore stores per-user records, scenarios and alerts; Firebase Auth (anonymous, email, Google) secures every call with verified ID tokens; FCM delivers alerts. Safeguards: untrusted-data prompts, schema-validated output, no probabilities, no AI-made numbers, and every result labelled as AI or fallback. Flutter client; 51 backend tests pass.
